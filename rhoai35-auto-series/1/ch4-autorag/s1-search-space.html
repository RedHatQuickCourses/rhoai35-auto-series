Benchmarking the RAG Search Space

Estimated reading time: 15 minutes.

Objective

Prepare evaluation input for AutoRAG and interpret the diagnostic metric triad that scores each retrieval configuration.

AutoRAG Demo - OpenShift AI 3.5

Input preparation

AutoRAG is driven by an evaluation JSON dataset. Each test case provides a question, correct_answers (multiple valid phrasings), and correct_answer_document_ids that identify the grounding sources.

Automated search space and optimization

AutoRAG grid-searches the configuration space that practitioners normally tune by hand:

  • Chunking strategy — recursive vs. hybrid structural

  • Search mode — vector vs. hybrid

  • Fusion strategy — RRF or weighted

  • Embedding model — for example, BGE-M3, with multilingual auto-detection

The diagnostic metric triad

Evaluate each run against three complementary metrics:

  • Answer Faithfulness — a hallucination check.

  • Answer Correctness — a ground-truth match.

  • Context Correctness — retrieval accuracy.

Production handoff and inspection

Debug pipelines visually with the Pipeline DAG, then export Responses API code snippets (cURL, Python, Go, Node.js) or indexing and inference Jupyter notebooks for handoff.
