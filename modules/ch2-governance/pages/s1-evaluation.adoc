== Under the hood: model stacking

AutoML uses AutoGluon to train and stack multiple model families — XGBoost, LightGBM, CatBoost, and FastAI/DNNs — so the leaderboard reflects an ensemble of the best performers rather than a single algorithm.

== Report card analysis

Evaluate candidates using the metrics that fit the task: Accuracy for classification, $R^2$ for regression, and MASE for time series. Go deeper with explainability and validation tools:

* Feature Importance
* Confusion Matrices
* ROC and PR curves
* Rolling Time Series backtesting

== Production handoff

Promote a winning model through a repeatable path: export the notebook, register the model in the Model Registry, and deploy to the AutoGluon ServingRuntime to expose a KServe v2 REST API.

You can now validate and deploy a predictive model with confidence. The next chapter shifts from numbers to text, introducing generative AI in the GenAI Playground and using MLflow to govern prompts the same way you just governed models.
